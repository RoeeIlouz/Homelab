# Monitoring & Observability Stack

A resource-efficient monitoring solution tailored for Raspberry Pi 5.

## Components
- **Beszel**: Hub and agent for CPU, RAM, disk, network, and temperature telemetry.
- **Uptime Kuma**: HTTP/TCP/Ping monitoring with rich notifications (Discord, Telegram, Ntfy).
- **Dockpeek**: Modern web UI for Docker container state and logs.

## Port Map
- Beszel: `8090`
- Uptime Kuma: `3001`
- Dockpeek: `3420`
